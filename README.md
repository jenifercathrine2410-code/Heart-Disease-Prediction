# Heart Disease Prediction using Logistic Regression

## Project Description
This project predicts whether a person has heart disease using Machine Learning.

##  Algorithm Used
- Logistic Regression

##  Dataset
- Heart Disease Dataset

##  Technologies
- Python
- Pandas
- NumPy
- Scikit-learn

##  Steps Involved
1. Data Collection
2. Data Preprocessing
3. Model Training
4. Model Evaluation
5. Prediction

##  Result
- The model predicts heart disease with good accuracy.
